# Tallow Reach

A 3D space sim: mine asteroids, take contracts, fight raiders, and build up Meridian Outpost.

- **Play:** `npm install && npm run build`, then open `game/tallow-reach.html` in a browser.
- **Develop:** `npm run watch` rebuilds on save.
- **Test:** `npm test`.
- **The big picture:** [docs/VISION.md](docs/VISION.md) (what the game will be), [docs/ROADMAP.md](docs/ROADMAP.md) (what is done and next), [docs/REFACTOR_PLAN.md](docs/REFACTOR_PLAN.md) (the step-by-step plan to get the code ready, with prompts), [docs/TARGET_ARCHITECTURE.md](docs/TARGET_ARCHITECTURE.md) (where the code is heading).
- **New AI chat?** Start with [docs/HANDOFF.md](docs/HANDOFF.md) and the starter prompt in [docs/AI_PROMPTS.md](docs/AI_PROMPTS.md).
- **Is the game still fine?** [TESTING-BASELINE.md](TESTING-BASELINE.md) (a 10-minute click-through).
- **Starmap playtest:** [TESTING-STARMAP.md](TESTING-STARMAP.md) (step 11B: free local warp, permanent core labels, clickable gate neighbours, zoom-scaled pan/cores, M chart, click/right-click travel, save v16).
- **Architecture:** see [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Recipes for adding ships, contracts, enemies, screens and story: [docs/HOW_TO_ADD.md](docs/HOW_TO_ADD.md).
- **Working with an AI assistant:** [docs/AI_PROMPTS.md](docs/AI_PROMPTS.md) (starter prompt) and [docs/CHANGELOG.md](docs/CHANGELOG.md).
- Each folder in `src/` has its own short `README.md`.
- `reference/original-tallow-reach.html` is the untouched prototype, kept for comparison.
