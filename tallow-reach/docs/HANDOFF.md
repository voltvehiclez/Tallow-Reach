## Where the game is right now

Tallow Reach is a three.js space game played from one built HTML file. You fly out of **Meridian
Station** in the **Meridian Station** pocket (`reach`) of the **Meridian System**, take contracts,
mine asteroids, fight Newbie Raiders, and dock to spend the money. M warps to the next pocket of the
current system: today that is **Kestrel Hollow** (`hollow`, empty), and M again returns. A ship is
modules in bays (powerplant, cell, thrusters, shields, hull, cannons, mining beam, missiles); empty
bays mean the ship lacks that thing. Hostiles are Newbie Raiders. Everything a place holds is one
stock of items (`{ itemId: count }`) from `src/data/items.js`.

## What step 10 changed (complete, owner-playtested)

- **Systems and pockets.** `src/data/terms.js` holds generic nouns (`mapNode: "system"`,
  `flyable: "pocket"`), one line each. `src/data/places.js` holds `PLACES` (systems + pockets) and
  `PLACE_DEFS` (features: station, asteroidField, spawner, planet). Meridian is a **station feature**
  inside `reach`, not a child place. Internal ids `reach`/`hollow` are unchanged save ids.
- **Generic loader / containers.** `sim/places.js` loads a place's entities; `state.places` /
  `placeWorld(id)` hold per-place entity lists. `state.world` and `state.place` are local-pilot
  aliases. Hard-coded `FIELD_CENTER`, `FIELD_SECTOR`, `STATION_POS` and parked rock lists are gone.
- **Per-pilot place/warp.** Each player owns `place` and `warp`; `sim/step.js` runs shared systems
  once per occupied pocket. One pilot warping does not move another or clear a fight another active
  pilot is still having. M cycles all pockets of the current system (any number).
- **Save v14.** `world.place` replaces `world.sector`; v13 `sector` migrates where valid, older saves
  default to `reach`. Storage keys (`tr1`, `tr_s1..tr_s3`) and `TR1:` codes unchanged. Loading a
  station save opens docked; loading an away save resumes flying at that pocket's arrival point with
  a launch-style refresh (exact position/velocity/shield/boost are not saved). Successful local warp
  arrival autosaves. Station label renamed **Meridian Outpost → Meridian Station**.
- **Playtest fixes (2026-11-08).** Three bugs the owner found: (1) sound was dead after resuming out in

## Standing rules (do not break)

- Plain ES modules; no new npm dependencies (the only planned exception is a small networking
  library at the multiplayer step). Tuning numbers belong in `src/data/`.
- Simulation stays render/audio/input-free; entities are data; gameplay randomness uses
  `util/rng.js`; connect systems through `util/events.js`.
- Saves stay backward-compatible: bump `SAVE_VERSION`, add migration, add a test.
- Never hand-edit generated `game/tallow-reach.html`. After changing `src/`, run `npm run build`
  and `npm test` and report honest results.
- Every change gets a short top entry in `docs/CHANGELOG.md`; above 15 full entries, move oldest
  verbatim to `docs/CHANGELOG_ARCHIVE.md` until 10 remain and add index lines.
